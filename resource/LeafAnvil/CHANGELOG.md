# Changelog

All notable changes to `LeafAnvil` are documented in this file.

## [Unreleased]

## [0.3.0] - 2026-11-20

### Added
- **`.lca` Format Version `3` (`0x0003`, `LCA-ICD-3.0`) lossless compression and codec layer (`anvil-api-ADR-004`, `anvil-api-ADR-005`, `REQ-RTP-S-004`, `REQ-RTP-S-005`):**
  - **Block-conditioned Eikonal `SkyLight` & `BlockLight` prediction with `B1` octant-bitmask packed 4-bit residuals (`LcaV3Codec`):** Frozen `LCA_LIGHT_TABLE_V1` (including `minecraft:tinted_glass` opacity `15`), bounded fixed-point Eikonal BFS, and `64-bit` octant-bitmask + packed 4-bit non-zero residuals wrapped behind `VarInt payloadByteLen` (`O(1)` `skipLightChannel` on runtime `AnvilChunkView` reads, excluded for `storageKind == 3` `MAP_TILE`).
  - **Columnar `block_ticks` / `fluid_ticks` and template-deduplicated `block_entities` (`boilerplateFlags16` bit `15`, `0x8000`):** Single-pass extraction in `LcaStreamingNbtEncoder` with automatic lossless (`L_inf = 0`) fallback to `Bit 10` (`residualNbtSlice`) for non-vanilla/modded schemas.
  - **Per-`SectionFrame` adaptive successive rank-exclusion `Delta-Roaring` (`paletteLen == 0` -> `secExtFlags`) & non-mutating `litLen[256]` cost estimator (`ADR-005` Candidate `D`):** `CBIT T6b`-enforced rank-exclusion decoding with opt-in archival compaction support and `0 us` decode overhead.
  - **Full `0x0002` backward read compatibility:** `LcaRegionReader` accepts `{0x0002, 0x0003}` while failing closed (`CBIT T5`/`T7`) on any `v3` sentinel inside `v2` archives.

### Changed
- **Single-pass Fast-Greedy `LCD2` (`0x4C44`) encoder and bounded live dictionary training (`anvil-api-ADR-005` Candidate `E`, `0 B` wire change):** Replaced the per-chunk `48 KiB` hash-table `Arrays.fill` and exhaustive hash-chain search on live `Mode B` saves (`lcd2Level <= 2`) with a zero-fill, epoch-tagged direct-mapped 4-byte hash table (`LcaSectionCodec#encodeAtomicDictBodyFastGreedy`), bounded live dictionary training (`DICT_FAST_TRAIN_MAX_CHUNKS = 8`, `DICT_FAST_TRAIN_CAP_BYTES = 4096`), and dirty-only `syncAtomicDictToSegments()` flushing while keeping the exhaustive parser for archival compaction (`lcd2Level >= 3`). Cuts `LCD2` encode time `9.40x` (`41.09 us` vs `386.30 us`) and speeds up decode `7.2%`, bringing warmed 64-chunk single-pass `Mode B` saves down from `948-967 us` to `438.73 us` (`v3-Columnar`, faster than vanilla `.mca` Zlib `442.98 us`) and `500.69 us` (`v3-Default` with `Eikonal+B1` at `47.16%` of `.mca` size / `2.12x` smaller, `View Rd` `65.99 us` vs `.mca` `127.36 us`).
- **Published `LeafAnvil` source tree on `LeafCraftDev/LeafAnvil` under `PolyForm-Noncommercial-1.0.0 OR LicenseRef-LeafCraft-Commercial` (`leafanvil-ADR-008`, `ADR-108`, `ADR-126`):** Dual-licensed `resource/LeafAnvil` (`LICENSE`, `fabric.mod.json`, `neoforge.mods.toml`) so developers, auditors, and hobbyist players can freely inspect, modify, and build `LeafAnvil` from source for personal singleplayer, non-commercial private servers, benchmarking, and private testing under `PolyForm-Noncommercial-1.0.0`, while keeping monetized/commercial server hosting under `LicenseRef-LeafCraft-Commercial` and preserving `MIT` licensing on `LCA-ICD-1.0`, `api/anvil-api`, `LeafAnvil-Net`, and `rust/lca-format`.

## [0.2.1] - 2026-11-16

### Added
- **Bounded worker-core cap, Chunky / `ScanTask`-style `BudgetPacer` duty-cycle pacing, tick-health backoff, and `/leafanvil pause|resume|cancel` controls for forced world conversion (`leafanvil-ADR-001`, `commands-api-ADR-001`, `REQ-RTP-S-002`, `REQ-RTP-S-005`):** Replaced unbounded `ForkJoinPool.commonPool()` `parallelStream()` saturation in `LeafAnvilWorldConverter` with dedicated low-priority `LeafAnvil-Converter-*` workers (`convert-worker-threads`, default `0` = auto `1-2` with `C2ME` else `1-4` quarter-cores, or per-run `workers=<n|auto>`), `BudgetPacer` active/rest duty-cycle pulses (`convert-duty-cycle: 0.50`), reactive TPS (`convert-min-tps: 18.5` with `+0.5` TPS hysteresis) and tick-overtime (`convert-max-overtime-ms: 10`) backoff across `convertWorldToLca`, `convertWorldToMca`, and `healAndVerifyWorld`, `5s` windowed rate/ETA telemetry in chat and `/leafanvil status`, and cooperative `/leafanvil pause`, `/leafanvil resume`, and `/leafanvil cancel` subcommands.

### Changed
- **Removed deprecated `LCD2` migration configuration and API shims (`leafanvil-ADR-001`, `leafanvil-ADR-003`):** `LeafAnvilConfig` (`config.yml`) now accepts `lcd2-level` and `mode-b-lcd2` exclusively without legacy fallback keys, and deprecated wire/storage delegating shims were removed across `LcaWireStreamProtocol`, `LeafAnvilConfig`, and platform telemetry records.
- **Crash-durable `.lca` region close, migration, and conversion writes (`anvil-api-ADR-002`, `anvil-api-ADR-003`, `leafanvil-ADR-001`, `REQ-RTP-S-005`):** Explicit `LcaRegionFileStorage#close()` and `closeRegion(rx, rz)` calls now force dirty file channels to disk by default (`-Dleafanvil.fsync.onClose=true`) while keeping LRU cache eviction unforced (`closeWithoutForce()`), and lazy legacy migrations, `/leafanvil convert`, and `/leafanvil heal` stage writes through `LcaRegionWriter.writeBytesAtomicallyDurable` (`FileChannel#force(true)` prior to `ATOMIC_MOVE`, offloaded via `AnvilIoPool` on primary/region threads) plus a JVM shutdown flush hook for archives reopened during post-disable server saves.

### Fixed
- **Re-running `/leafanvil convert` (`format=lca`) on an already-converted world overwrote `r.x.z.lca` onto itself and moved it to `.lca.bak` or deleted it (`leafanvil-ADR-001`):** Split legacy (`.mca`, `.linear`, `.b_linear`) and `.lca` filename patterns in `LeafAnvilWorldConverter`, deduplicated per-region conversion candidates, and skipped legacy files when a valid live `r.x.z.lca` archive already exists on disk.
- **Concurrent `createIfAbsent` region opens joining an in-flight read-only miss could truncate each other's newly created `.lca` archive, and `invalidateRegionCacheState` retained stale `LcaRegionReader` file headers (`anvil-api-ADR-003`):** Retried single-flight `openingRegions` registration before creating empty archives in `LcaRegionFileStorage#getOrOpenRegion` and evicted `LcaRegionReader` `CachedFileHeader` entries during `invalidateRegionCacheState`.
- **Region existence I/O faults, `region-file-compression=lz4` (`compressionId=4`) stream writes, and partial world-hook failures could lose or corrupt chunk data (`anvil-api-ADR-001`, `leafanvil-ADR-001`, `REQ-RTP-S-004`):** `NmsRegionStorageInterceptor#onDoesChunkExist` now logs `WARNING` and throws `UncheckedIOException` instead of reporting chunks missing on I/O or corruption errors, `LcaRegionFileStorage.decodeAnvilChunkPayload` decodes mode `4` (`LZ4Block`) payloads via `Lz4BlockDecoder` and rejects unknown codecs or `< 5`-byte stream headers with `IOException`, and `interceptWorldStorages` / `detachWorld` restore original `regionCache` maps on partial attachment failure or world detach.
- **Inline `#` comments in `config.yml` silently altered parsed values and scheduler-less batch tasks ran on the calling thread (`REQ-RTP-S-005`):** `LeafAnvilConfig` now strips unquoted inline `#` comments before parsing scalars, and `LeafAnvilRuntime#runBatchTaskAsync` dispatches fallback batch tasks off-thread when executed on primary or region threads.
- **Paper Starlight omitted zero-`SkyLight` subterranean cave sections and high-altitude (`Y >= 128`) enclosed cave sections could reload or stream with full `15` sky light extrusion (`anvil-api-ADR-003`, `leafanvil-ADR-002`, `leafanvil-ADR-003`):** Preserved `starlight.skylight_state` / `starlight.blocklight_state` initialization states (`1` zero-light vs `2` initialized `byte[2048]`) across `LcaStreamingNbtEncoder`, `LcaRegionWriter`, `LcaSectionCodec`, and `LcaRegionReader` without altering open-sky air extrusion, and resolved `skyConst4 = 0` for enclosed mountain/hillside caves and non-Overworld dimensions across `PaperLeafAnvilPlugin`, `LcaSectionBridge`, and `LcaInMemoryChunkCoordinator`.

## [0.2.0] - 2026-11-11

### Changed
- **Breaking Beta Format Bump to `.lca` Format Version `2` (`0x0002`) & 100% Pure-Java Packaging (`anvil-api-ADR-003`, `LCA-ICD-1.0`):** Standardized on `.lca` format version `2` (`0x0002`) without legacy `0x0001` upconversion and removed shaded `com.github.luben:zstd-jni` native binaries from `LeafAnvil` and `LeafAnvil-Net` so both deliverables are 100% pure Java with zero JNI/native library payloads.

### Added
- **`.lca` Format Version `2` (`0x0002`) and Pure-Java Continuous Atomic Layer 2 Region Dictionary (`LCD2`, `0x4C44`) (`anvil-api-ADR-003`, `LCA-ICD-1.0`):** Compacted section Delta-Roaring cursor domains over `octreeOccupancyMask64` (`01:H_3` octant compaction and `00:YZX`/`10:Y+H_2` horizontal slab compaction), expanded `TAG_SINGLETON` (`subTag 0..3`), `TAG_DELTA_RUN` (`4|4`, `5|3`, `6|2`, `7|1`), Word-Masked `TAG_BITMAP`, and Gray light `planeModes8` `mode 01`, and implemented a pure-Java `0x4C44` (`LCD2`) Continuous Atomic Layer 2 Region Dictionary protected by downward-growing Extended Hamming `(72, 64)` `SEC-DED` syndromes (shrinks `1_21_R1` 64-chunk regions to `272,648 B` / `51.2%` of `.mca` in Mode A, `-8.9%` smaller than `.linear`, with `25.28 us` cold / `24.80 us` warm Mode A 1-chunk reads).
- **In-memory `.lca` section coordination (`LcaSectionBacking`, `LcaInMemoryChunkCoordinator`, `leafanvil-ADR-002`), free `MIT`-licensed `LeafAnvil-Net` wire-only server TX + client RX artifact (`:resource:LeafAnvil:leafanvil-net`, `LcaClientWireReceiver`), and negotiated client / inter-server `LCAS` (`0x4C434153`) & `LCAB` (`0x4C434142`) wire streaming (`LcaWireStreamProtocol`, `LcaRemoteStreamCodec`, `LcaBoundedSlabPool`, `leafanvil-ADR-003`):** Compact `(baseFrame, dirtyOverlay)` section backing with `ZeroBitStorage` heap eviction (`MixinLevelChunkSection`, `MixinPalettedContainer`), negotiated `leafanvil:chunk_stream_handshake` (`LCA_NET_V1`), client revisit slab cache (`ClientChunkSlabCache`), two-tier bounded hot/warm slab pool (`LcaBoundedSlabPool`), `2-byte` `EntryCleanAck`, `4-byte/voxel` `EntryPatchDelta`, stored-Zlib proxy framing (`MixinCompressionEncoder`), and full multi-loader wire-only server TX + client RX packaging in `LeafAnvil-Net-<version>.jar` (with on-disk `NmsRegionStorageInterceptor`, `LeafAnvilWorldConverter`, and `/lca` commands isolated to commercial `LeafAnvil-<version>.jar`).
- **Sub-chunk `.lca` block patching (`ChunkPatchTail`, `HAS_CHUNK_PATCH_TAIL = 0x4000`, `LCA-ICD-1.0` Section 8.3) and unified `RegionFileResolver#patchChunkBlocks`:** Appends Slab-Local Micro-Palette extensions and per-section voxel, light, and heightmap patches (`LcaRegionWriter#patchChunkBlocks`, `LcaSectionCodec#encodeChunkPatchTailBytes`, `AnvilReader#patchChunkInMcaBytes`) with $O(1)$ residual-tail seek during `readChunkView`, `readColumnProbe`, and `readTerrainProbe` without full-chunk NBT decode/re-encode (`leafanvil-ADR-002`, `leafanvil-ADR-003`).

### Fixed
- **Concurrent Moonrise worker reads and dictionary growth during high-throughput generation (such as `Chunky`) could publish a stale `cachedParsedDict` snapshot (`CorruptRegionEntryException: CBIT T7: Slab-local globalStateId ... out of range`):** Synchronized `LcaRegionWriter.LcaLiveArchive#getOrBuildParsedHeaderAndDict` snapshot construction/publication and invalidated `cachedParsedDict` in `registerNewBlockStateId`, `registerNewBiomeId`, and `rollbackDictionaryToBookmark` before publishing new block-state or biome IDs.
- **Out-of-cache `.lca` region opens on large (`16k`+) world borders issued `2,050` syscalls per 1,024-chunk region and eagerly built the `TreeMap` free-slab allocator on read-only opens:** Clean `LcaLiveArchive` opens now trust verified `SEC-DED` pointer syndromes + trailing `LCA1_END` canary (`2` `pread` syscalls, `0` `ch.size()` calls - `8.5x-16.3x` faster region open), and `ensureFreeSlabPoolInitialized()` defers free-slab `TreeMap` construction until the first write.
- **Unpromoted FIFO cache eviction and concurrent read/compaction race on live region eviction:** Replaced FIFO / hash-bucket eviction in `LcaRegionFileStorage` (`regionCache`, `readChannelCache`) and `LcaRegionReader` (`FILE_HEADER_CACHE`, raised to `4,096` headers) with lock-free Second-Chance Clock LRU promotion, coalesced `headerOnlyChannelMode` `compact()` into a single `pread`/`pwrite` pass completed prior to `regionCache` removal, routed `removeChunk` through the 4-epoch `CoW` grace ring, and added `.lca` support to `AnvilRegionOccupancyCache#isOccupied`.
- **`ClassCastException` on `RegionFileStorage.regionCache` implementations storing `Optional<RegionFile>` values:** `NmsRegionStorageInterceptor` now inspects generic `regionCache` type parameters (`usesOptionalCacheValues`) and wraps `$$LeafAnvilRfBridge` instances in `Optional.of(...)` when required.

## [0.1.0] - 2026-11-01

### Added
- Unified multi-loader `.lca` (LeafCraft Anvil) world save format plugin & mod (`LeafAnvil-0.1.0.jar`) for Paper, Folia, Spigot, Fabric, and NeoForge (`leafanvil-ADR-001`, `anvil-api-ADR-002`, `anvil-api-ADR-003`).
- Zero-fork runtime `RegionFileStorage` and Moonrise bytecode interceptor (`NmsRegionStorageInterceptor`) generating `$$LeafAnvilCacheBridge` (`Long2ObjectLinkedOpenHashMap`) and `$$LeafAnvilRfBridge` (`RegionFile`) subclasses at runtime to route `region/` (`STORAGE_KIND_REGION_VOXEL = 0`), `entities/` (`STORAGE_KIND_ENTITIES = 1`), and `poi/` (`STORAGE_KIND_POI = 2`) reads, stream writes, Moonrise `write(ChunkPos, ByteBuffer)` writes, existence checks, clears, flushes, and closes through disk-backed `.lca` (`LcaRegionFileStorage` / `LcaLiveArchive`), plus startup class prewarming (`prewarmAnvilClasses`) for shutdown saves.
- Pre-open vanilla `RegionFile` cache flush/close, Moonrise `nonExistingRegionFiles` (`LongLinkedOpenHashSet`) clearing, Moonrise `RegionFile` field initialization (`version = VERSION_NONE`, `info`, `recalculateCount`, `oversized`, `path`), and live `RegionFileStorage.folder` dimension directory resolution supporting classic (`world/`, `DIM-1/`, `DIM1/`) and Minecraft `26.1+` unified `dimensions/<namespace>/<dimension>/` layouts.
- Lazy on-open `.mca` / `.linear` / `.b_linear` (`BufferedLinear`) -> `.lca` atomic migration (`tryMigrateLegacyRegion` preserving `.bak` backups), configurable Mode B (`LCD2` `0x4C44` Continuous Atomic Region Dictionary with Extended Hamming `(72, 64)` header parity) vs Mode A (`0-LZ` direct walk), reversible batch world conversion (`LeafAnvilWorldConverter#convertWorldToLca` and `convertWorldToMca`), `256B` Copy-on-Write (`CoW`) free-slab compaction (`compactOpenRegions`), and 4-tier Extended Hamming `(72, 64)` SEC-DED + `256B` slab reverse-scan + section `octreeOccupancyMask64` quarantine + `CoW` rollback bit-rot recovery (`healAndVerifyWorld`).
- Platform-neutral `/leafanvil` (alias `/lca`) `CommandsAPI` command tree (`status`, `convert [world=<name|all>] [format=<lca|mca>]`, `compact [world=<name|all>]`, `heal [world=<name|all>]`, `reload`) with single-flight async batch execution (`REQ-RTP-S-005`), configurable `config.yml` / `messages.yml` feedback (`REQ-RTP-S-007`), and automatic extraction of the open-source MIT `.lca` Interface Control Document (`ICD.md`).
- Continuous 8-platform statistical A/B/C benchmark and cold-restart persistence verification driver (`scripts/bench_lca_multiplatform.py`, `120` completed runs across Paper `26.2`, Folia `26.2`, Leaf `26.2` `.linear`, Leaf `26.2` `.b_linear`, Fabric `26.1.2` `+ C2ME`, and NeoForge `26.1.2` `+ C2ME`, plus `--verify-persistence`).
